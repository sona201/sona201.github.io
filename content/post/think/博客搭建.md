### 博客安装
```
arch -arm64 brew install hugo
brew install hugo

git clone https://github.com/sona201/blogs.git
git submodule
git submodule init
git submodule update
```

### git子模块功能安装使用

[Git submodule 子模块的管理和使用](https://www.jianshu.com/p/9000cd49822c)

```
git submodule add https://github.com/sona201/hugo-theme-stack themes/hugo-theme-stack

# 删除 submodule 方式，自定义主题
rm -rf  .gitmodules # 删除项目目录下.gitmodules文件中子模块相关条目
vi .git/config # 删除配置项中子模块相关条目
rm .git/module/* 删除模块下的子模块目录，每个子模块对应一个目录，注意只删除对应的子模块目录即可
git rm --cached themes/hugo-theme-stack -rf
```
